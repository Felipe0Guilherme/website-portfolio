# Felipe Guilherme — Portfólio Pessoal

> Site portfólio pessoal de **Felipe Guilherme**, Desenvolvedor Full Stack Jr baseado em São Paulo, SP. Apresenta projetos, habilidades técnicas, timeline de carreira e feedbacks reais de entrevistas.

🔗 **Demo ao vivo:** [website-portfolio-theta-ashen.vercel.app](https://website-portfolio-theta-ashen.vercel.app)

---

## 👨‍💻 Sobre

Portfólio desenvolvido em HTML, CSS e JavaScript puro — sem frameworks — com foco em performance, design moderno e apresentação clara das habilidades e projetos do desenvolvedor. O site conta com seções de apresentação, stack técnico, projetos, timeline interativa, feedbacks de entrevistas e formulário de contato.

---

## 🗂️ Estrutura do Projeto

```
website-portfolio/
├── index.html       # SPA — toda a estrutura do portfólio em página única
├── style.css        # Estilos globais, layout responsivo e animações
├── script.js        # Interatividade, Sparkles canvas, timeline e comportamentos de UI
└── assets/          # Imagens, ícones e demais recursos estáticos
```

---

## 🛠️ Tecnologias

- **HTML5** — Estrutura semântica em página única (SPA) (57.2%)
- **CSS3** — Layout responsivo, Flexbox/Grid, animações e design system próprio (31.2%)
- **JavaScript** — Canvas Sparkles, interatividade da timeline, integrações (11.6%)
- **Formspree** — Integração do formulário de contato sem backend
- **Vercel** — Deploy e hospedagem contínua

## 📦 Como Rodar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Felipe0Guilherme/website-portfolio.git
   ```

2. Navegue até a pasta:
   ```bash
   cd website-portfolio
   ```

3. Abra o `index.html` diretamente no navegador ou use o **Live Server** no VS Code.

> Não há dependências de npm ou build step — o projeto roda diretamente no browser.

---

## 🌐 Deploy

O portfólio está hospedado na **Vercel** com deploy automático a partir do branch `main`.

Para fazer um novo deploy após alterações:
```bash
git add .
git commit -m "feat: descrição da alteração"
git push origin main
```
A Vercel detecta o push e faz o deploy automaticamente.
